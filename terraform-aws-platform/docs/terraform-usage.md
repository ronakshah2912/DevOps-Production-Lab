# Terraform Usage

## Initialize Terraform

```bash
cd terraform-aws-platform/environments/dev
terraform init
```

## Format Code

```bash
terraform fmt -recursive
```

## Validate Code

```bash
terraform validate
```

## Preview Changes

```bash
terraform plan
```

## Apply Infrastructure

```bash
terraform apply
```

## View Outputs

```bash
terraform output
```

## Destroy Infrastructure

```bash
terraform destroy
```
