# SRE Documentation

This folder contains service reliability documentation for the DevOps Production Lab.

| File | Purpose |
|---|---|
| `service-reliability-document.md` | Defines SLI, SLO, SLA, error budget, incident severity levels, alerts, rollback criteria, and post-incident review process |

| Target | Value |
|---|---:|
| Availability SLO | 99.9% |
| Latency SLO | p95 under 300ms |

| Monthly Error Budget | 43.2 minutes |
